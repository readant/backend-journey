# 工具与配置索引

本目录沉淀**开发环境、编辑器插件、工具链**的安装与使用经验，与 [学习教程](../learning/)（语法知识）、[速查卡片](../cheatsheet/)（知识点）、[组件索引](../components-index.md)（可复用代码）并列。

> 定位：解决「这个工具怎么装、怎么配、怎么用」的问题。遇到环境问题先查这里。

## 组织规则

```
docs/tools/
├── README.md            # 本索引
└── <工具名>/            # 按工具/产品分类，如 cursor、maven、mysql
    └── <主题>.md        # 该工具下的具体文档
```

- 每个工具一个子目录，目录名小写英文
- 文档命名：主题式（如 `java-plugins.md`），避免泛化的 `使用说明.md`
- 新增工具文档后，在下方表格登记
