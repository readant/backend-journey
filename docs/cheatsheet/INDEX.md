# 速查卡片索引

本目录存储从实战中提炼的核心知识点速查卡片。

> 📖 语法还没打牢？先走 [Java 语法学习导航](../learning/README.md)（零基础 → 能看代码），再回来看实战速查。

## 使用说明

1. 每次完成一个功能开发后，AI 会自动生成速查卡片
2. 卡片按功能命名，格式为 `功能名.md`
3. 卡片按项目归档，放在对应项目的 `docs/cheatsheet/` 下
