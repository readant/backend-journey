# AI 专属上下文目录

> ⚠️ **重要：本目录由 AI 自动维护，人类不要手动编辑。**
>
> 如果你改了这里的文件，会出现以下问题：
>
> - AI 判断错学习阶段，重复讲已掌握的内容，或者跳得太快
> - AI 不知道下一步该教什么，失去方向感
> - 进度表状态错乱，复习时找不到薄弱点
>
> 如果发现进度不准，请直接在对话里告诉 AI「我其实还没掌握 XXX」或「加速，跳过基础」，AI 会自己更新这个目录。

---

## 文件说明

| 文件                  | 谁读写   | 用途                                                                                                                       |
| --------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------- |
| `progress-tracker.md` | AI 读+写 | **当前学习进度**：在哪个项目、哪个阶段、哪些知识点已掌握。AI 每次对话开头必读，教完必更 ✅ 标记。                          |
| `knowledge-map.md`    | AI 只读  | **四层知识体系 + 概念速查**：某个技术点首次出现在哪个项目？Java 概念的通俗比喻是什么？教新知识点时 AI 来这里查现成的比喻。 |
| `project-roadmap.md`  | AI 只读  | **四项目路线图**：每个项目拆哪些功能、覆盖哪些技术、简历描述怎么写。跨项目切换时 AI 来这里读。                             |
